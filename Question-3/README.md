Estimate Shadowing Variance

estimates the shadowing standard deviation from the residuals of the three fitted regression models:

Closed-form Linear Regression

Batch Gradient Descent

Stochastic Gradient Descent (SGD)

The calculation follows:

[
\hat{\sigma}^2 = \frac{1}{N}\sum_{i=1}^{N}\epsilon_i^2
]

and therefore:

[
\hat{\sigma}=\sqrt{\frac{1}{N}\sum_{i=1}^{N}\epsilon_i^2}
]
